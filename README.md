# AYUSH 🏥

AYUSH is a medical professional platform designed for **AYUSH students** to learn, build verified skills, earn certificates, check internship eligibility, and connect with healthcare organizations.

### 🔄 Core Workflow

**Learn → Assess → Get Certified → Prove Skills → Check Eligibility → Get Internship**

### 🎓 For Students
- Medical professional profile
- Academia & courses
- Assessments
- Verified certificates
- Skill matching
- Internship opportunities
- Eligibility checking
- Internship applications

### 🏥 For Organizations
- Organization profile
- Post internships
- Define eligibility & required skills
- View student profiles
- Check eligibility
- Shortlist & select students

### 📚 For Academia
- Create medical courses
- Learning materials
- Assessments
- Certificates
- Student progress
